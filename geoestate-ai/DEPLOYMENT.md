# Deploy MakaanX to Render

This project is configured as one Render web service. The Docker image builds the React frontend and serves it from FastAPI, so the UI and `/api` endpoints share one origin.

## Deploy

1. Push this project to a GitHub repository. Do not upload `.env` files, virtual environments, databases, or `node_modules`; the root `.gitignore` excludes them. The current model artifact and property CSV are required and are included in the Docker image.
2. In Render, choose **New → Blueprint**, connect the repository, and apply `render.yaml`.
3. Wait for the service health check at `/api/health` to pass, then open the Render URL.
4. Email/password registration works without third-party credentials. To enable Google sign-in, set `GOOGLE_CLIENT_ID` in the Render service environment to your OAuth web client ID. Add the deployed HTTPS origin (for example, `https://makaanx.onrender.com`) to that client’s **Authorized JavaScript origins**, then redeploy.

The session-signing secret is generated by Render and secure cookies are enabled for HTTPS.

## Demo storage limitation

This configuration uses SQLite on the free service's temporary filesystem. Accounts and prediction history can disappear when Render restarts, redeploys, or replaces the instance. This is suitable for a temporary demonstration only; use a persistent disk or managed database before relying on saved account data.

Render's free web service may sleep when idle, so the first request after inactivity can take longer while the service starts.
